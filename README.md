# Mini Task Manager 📅

一個使用原生 Web 技術開發的輕量級待辦事項與個人行程管理系統。支援月檢視、周檢視、艾森豪象限表、任務細項安排、逾期事項追蹤與學期課表管理。

## 🌟 核心特色 (Key Features)

* **多檢視模式 (Multi-View Layout)**：
  * 📅 **主月檢視**：全月行程總覽，附帶直覺的任務色彩圖例說明（藍：行程 / 橘：報告 / 紅：考試 / 紫：社團）。
  * 📊 **周檢視**：以時間軸精準計算並呈現每日時段卡片。
  * 📌 **艾森豪象限表**：依重要度與緊急度自動分類任務，自動隱藏已完成事項。
  * 📝 **任務細項安排**：單向同步主行程，可在此頁面單向修改或新增獨立細項任務（綠色主題，不同步回主頁）。
  * ⚠️ **逾期事項**：自動彙整過期未完成項目，方便及時調整與補做。
  * 🎓 **115-1 課表**：建立固定學期課程，並支援單週出缺勤與「停課」狀態切換。
* **豐富任務欄位**：支援時間區間（開始/結束）、重要標籤、顏色分類與詳細說明備註 (Description)。
* **自動時間排序**：所有視圖與清單皆嚴格按照「日期舊至新 ➔ 時間早至晚」排列。
* **純原生、零套件**：100% 使用 HTML5, CSS3 與 Vanilla JavaScript，無任何外部第三方套件依賴。
* **本機持久化**：透過 `localStorage` 保存所有行程與設定，關閉瀏覽器資料不丟失。
